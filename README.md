🛒 Blinkit Sales Analytics Dashboard
📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of Blinkit's grocery sales performance. The dashboard helps stakeholders monitor sales, product performance, outlet efficiency, customer preferences, and inventory insights through interactive visualizations and KPI tracking.

🎯 Business Objectives
Monitor overall sales performance.
Analyze outlet-level sales trends.
Evaluate product category performance.
Understand customer preferences based on fat content.
Compare outlet types and sizes.
Support inventory and sales optimization decisions.

📊 Dashboard Overview
